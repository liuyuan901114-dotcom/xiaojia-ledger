# 小家账本原型

面向 iPhone 窄屏设计的中文家庭收支记录网页应用（PWA）。数据保存在当前设备的浏览器中，不需要账号或云同步。

## 功能

- 快速记录每日收入与支出，支持日期、一级/二级分类和备注。
- 包含家庭生活、买菜消费、孩子学习等重点分类及明细。
- 查看月度、年度收支、结余、趋势和分类占比。
- 查看记账天数、笔数、连续天数和历史留痕。
- 设置攒钱密码，支持自由攒钱、定额攒钱和目标进度。

## 在 iPhone 上使用

Pages 发布完成后，在 iPhone Safari 打开项目地址，点“分享”→“添加到主屏幕”。首次打开需要联网，之后可离线使用。

项目地址：https://liuyuan901114-dotcom.github.io/xiaojia-ledger/

这是可安装的网页原型，不是 App Store 应用。账目只保存在安装它的设备上；攒钱计划在本机加密保存，忘记密码无法恢复。

## 本地预览

在项目目录运行 python3 -m http.server 4173，然后打开 http://localhost:4173。
